# 分镜拆解指南

## 拆解原则

每个镜头承载一个完整、连续的**叙事节拍**，描述要具体但不重复拆分。普通镜头默认 5 秒，范围 4-7 秒；如果用户消息包含目标视频模型固定时长规则，以目标模型规则为准。

只在场景切换、动作结果、视角重点或说话焦点明显变化时切新镜头。同一场景、同一动作链、同一说话焦点优先合并；不要把每个细小动作、表情或一句短对白单独拆成镜头。

## 镜头要素

1. **镜头标题**：3-5字概括核心内容（如"噩梦惊醒"）
2. **时间**：具体时分 + 光线描述
3. **地点**：场景完整描述 + 空间布局 + 环境细节
4. **景别**：远景/全景/中景/近景/特写
5. **角度**：平视/仰视/俯视/侧面/背面
6. **运镜**：固定/推镜/拉镜/摇镜/跟镜/移镜
7. **动作**：谁 + 具体怎么做 + 肢体细节 + 表情
8. **对话**：该镜头的完整对话
9. **画面结果**：动作的即时后果 + 视觉细节
10. **氛围**：光线 + 色调 + 声音 + 整体氛围
11. **时长**：普通镜头默认 5 秒；简单动作、反应和环境建立使用 4-5 秒，关键对白或连续动作使用 5-7 秒；若目标视频模型指定固定时长，必须按目标模型规则填写
12. **静态画面提示词**：`image_prompt`，用于首帧/尾帧/镜头图片生成
13. **视频提示词**：`video_prompt`，时间段从 0 秒开始并正好覆盖 `duration`；短镜头无需机械分段，若目标视频模型指定分段方式，必须按目标模型规则填写（必填）
14. **配乐提示词**：`bgm_prompt`，描述该镜头适合的配乐风格
15. **音效提示词**：`sound_effect`，描述该镜头关键环境音/动作音
16. **场景关联**：若能匹配已有场景，必须填写 `scene_id`
17. **角色关联**：填写 `character_ids`，绑定当前镜头涉及的 0 到多个角色

## 视频提示词格式

每个镜头必须包含 `video_prompt` 字段，用于驱动 AI 视频生成。以下是普通 5 秒镜头的默认格式示例；若目标视频模型规则另有要求，以目标模型规则为准：

```
0-5秒：<location>咖啡厅</location>，镜头从<role>小明</role>看手机的焦虑近景轻推到门口，门铃响，<role>小红</role>推门进入。
```

标签说明：
- `<location>地点</location>` — 场景标记
- `<role>角色名</role>` — 角色标记
- `<voice>角色名</voice>` — 画外音/旁白标记
- `<n>` — 时间段分隔符

## 使用步骤

1. 调用 `read_storyboard_context` 读取当前剧本、角色和场景
2. 先基于剧本完成镜头拆解，确保总时长和叙事连续性合理
3. 为每个镜头补全完整字段：`title / shot_type / angle / movement / location / time / character_ids / action / dialogue / description / result / atmosphere / image_prompt / video_prompt / bgm_prompt / sound_effect / duration / scene_id`
4. 调用 `save_storyboards` 一次性保存完整分镜
5. 如需调整，调用 `update_storyboard` 修改具体镜头

## 场景关联规则

- 优先使用 `read_storyboard_context` 返回的 `scenes`
- `location + time` 可明确匹配时，必须回填正确 `scene_id`
- 不要凭空生成不存在的场景 ID
- 如果剧本内容明显落在已有场景中，不要重复创造新场景描述

## 角色绑定规则

- `character_ids` 必须从 `read_storyboard_context` 返回的角色列表中选择
- 一个镜头可以没有角色，也可以绑定多个角色
- 只要镜头里有明确出场、被看见、发生动作或说话的角色，都应绑定进去
- 纯环境镜头、空镜头、物件镜头可以传空数组

## 质量要求

- `description` 要适合人读，`video_prompt` 要适合模型生成，二者不要互相替代
- 每个镜头都要写清前景、中景、后景及主体位置，补足关键环境物件、时间、天气、空气状态和空间材质；不能只写“电影感”“高质量”等空泛词
- 光影必须可执行：写出主光源类型与方向、明暗反差、色温、轮廓光或环境反射，并让相邻镜头的时间、光源和色彩连续
- 人物表演必须可观察：写出视线落点、呼吸、姿态重心、手部细节和符合剧情的微表情变化，避免只写“紧张”“悲伤”
- `image_prompt` 要突出单帧构图、前中后景、角色状态、环境物件、光源方向、色温、景深和真实材质
- `video_prompt` 要突出动作起点、连续动作、视线和微表情变化、镜头运动、环境动态及最终画面结果
- 必须完整继承 `read_storyboard_context` 返回的 `visual_style_lock`；角色图、场景图、宫格图、静态分镜图和视频不得发生画风切换
- 写实风格必须明确为 photorealistic live-action 真人摄影，保留真实人体比例、皮肤、发丝、布料和物理可信光影；严禁 3D、CGI、动漫、游戏角色、塑料皮肤、虚拟人和过度磨皮
- `bgm_prompt` 和 `sound_effect` 用简洁短语即可，但不能空泛到只有“紧张”“悲伤”
- 若存在旁白，统一写入 `dialogue`，格式为 `旁白：内容`
- 对白按约 3.5-4 个中文字/秒估时，并为动作和停顿预留少量时间；7 秒内放不下时才在自然语义边界切镜
- 合并重复情绪、无信息过渡和空泛特写；镜头数量上限只是安全上限，不是需要凑满的目标
- 不得新增当前剧本和已提取场景中不存在的地点、人物、对白、冲突、回忆、转折或悬念结尾

## TK 海外剧模式

仅当用户主动选择 TK海外剧拆解模式时启用以下规则，普通拆解和其他视频模型不套用：

- 先按本集每个已提取场景逐一建立镜头序列，再补充镜头细节；目标总时长 60-90 秒，因剧情完整度允许浮动到最多 100 秒。镜头数量不设固定目标，按每个场景的真实事件链和叙事节拍决定，不要把一集压成少量概述镜头，也不要为了凑数量扩写剧情。
- duration 必须按实际内容填写：通常 4-10 秒；连续动作、较长对白或需要完整展示动作结果时可使用 11-15 秒。4 秒以下或超过 15 秒时，应重新拆分或合并叙事节拍。
- 英文对白以剧本中的英文原文为准，保留原始大小写、标点、引号和说话人，不翻译、不改写。
- 英文台词后括号内的中文只作为翻译或辅助说明，不能写入 `dialogue` 或替代英文台词；括号内的表演状态只能写入动作或氛围字段。
- 逐场核对原始剧本，不能删掉关键动作、对白、冲突和结果，也不能为了凑镜头数量新增剧本外剧情。
